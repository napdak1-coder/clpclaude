=== cbmSource 구분 가능 여부 ===

현재 데이터 모델: c.cbm 한 필드만 존재 (Excel 'CFS CBM' 열 + 사용자 직접 입력 + 자동 채움 결과 모두 같은 곳).
→ 명시적 구분 X. 휴리스틱 (cbm ≈ W×L×H×Q 인지) 으로 추정만 가능.

권장: cbmSource: 'user' | 'calculated' | 'cfs' 필드 도입 (UnitSize / CargoSpec 둘 다).
- 'user'  — 사용자가 모달에서 직접 타이핑한 값
- 'cfs'   — Excel CFS CBM 열에서 읽은 값 (사용자 입력 기원)
- 'calculated' — UI 가 W×L×H×Q 로 자동 계산해서 채운 값 (classify allHaveCbm 판단에서 제외해야 함)
