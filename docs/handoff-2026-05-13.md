### 1-C. `packBestWithCandidateUnion` 신규 export 함수 (line 2900~3000)

**역할**: 컨테이너 셋 결정 시 declared CBM (사용자/CFS/about) 과 physical CBM (박스 W·L·H 합) 양쪽 후보를 모두 시도하는 packBest wrapper.

**흐름**
1. `options.fixedContainers` 있으면 기존 packBest 그대로 (사용자 강제 우선)
2. 첫 시도 — `packBest(cargoes, mode, { attachDebug: true })` → declared / physical 추출
3. 후보 union = `decideContainers(declared) ∪ decideContainers(physical) ∪ 첫 시도 셋`
   (multiset key = `cand.slice().sort().join("|")`)
4. 정렬 — 컨 수 asc → 총 capacity asc (작은 셋 우선)
5. 단락 평가 — 작은 셋부터 `packBest(fixedContainers)` 호출, valid 6 통과 시 즉시 채택
6. 모두 invalid 면 lex comparator 비교

**valid 6 조건 (`isValid6`)**
- unplaced 0
- strictStackAudit pass + violations 0
- 각 컨 maxCbm 초과 X
- 각 컨 maxWeight 초과 X
- cargoId 분산 0
- bookingNo 분산 0

**lex comparator (`compareLex`)** — 모두 invalid 일 때만 발동
```
키 = [unplaced, auditFail, hardViolations, cbmOverflow, weightOverflow,
      cargoSplit, bookingSplit, 컨 수, 총 capacity]
```
점수 합산 없음 (절대 룰 #2 준수).

**효과**
| 샘플 | 어제 (packBest 단독) | 오늘 (candidateUnion) |
|---|---|---|
| 망작 SG | 40FT+20FT | **40FT 1대** (단락 평가 valid 채택) |
| 4ST HM | 40FT×3 (148.6 m³, legacy) | 40+40+20 시도 → cbm overflow → **40×3 fallback** |

## 6. `components/input/UnitSizesModal.tsx` — 사이즈 모달

### 6-A. `baseCbm` prop 추가

행 기준 CBM 을 모달이 받아 unit cbm 자동 분배에 사용.

### 6-B. `defaultDraft` 자동 cbm 분배

- 사이즈 없는 행 (W·L·H 중 0) 이면 cargoType 무관하게 행 cbm 을 그룹 수로 균등 분배
- 그룹 N 개 → 각 unit cbm = baseCbm / N, 마지막 그룹은 반올림 오차 흡수
- 어제까지는 사이즈 없는 행에서 unit cbm 모두 0 → 알고리즘 부피 누락

### 6-C. `makeDraft` 폴백 변경

**Before**: unit weight 가 0 이면 `baseWeight` (행 총 무게) 를 직접 폴백 → 박스 1개 무게가 행 총 무게로 잘못 설정
**After**: `perUnit = baseWeight / baseQuantity` 폴백 (박스 1개 무게)

레이어 같은 케이스에서 unit weight 표시가 행 총 무게로 부풀려지던 결함 해소.

### 6-D. `correctInflatedUnitWeights` 자동 적용

ExcelImport 거치지 않은 raw 데이터의 unit weight 가 행 총 무게와 같이 들어있는 결함 케이스 보정.

### 6-E. `useEffect` dependency 축소

**Before**: `[open, props.initial, props.baseQuantity, props.baseSize.width, props.baseSize.length, props.baseSize.height, props.baseWeight]` → 메인 행 입력하면 모달 안 입력 reset
**After**: `[open, props.initial]` → 다른 행 열 때만 reset

### 6-F. `addRow` — 새 그룹을 메인 사이즈로 시작
